55# 4h&Google Fiber Support & FCR Analysis
* **Code:** [`google_fiber_analysis .ipynb`](projects/google-fiber/google_fiber_analysis.ipynb) | [`projects/google-fiber/`](projects/google-fiber/)
* **Goal:** Identify root-cause drivers behind repeat call center volume and 7-day First-Contact Resolution (FCR) failures across 3 markets.
* **Description:** Processed Q1 customer support telemetry logs using Pandas and Seaborn. Built company-wide weighted summary aggregations and executive charts isolating workload concentration.
* **Skills:** data cleaning, data analysis, ETL pipelines, weighted aggregations, data visualization.
* *(Technology:** Python, Pandas, Matplotlib, Seaborn.
* **Results:** Identified that **Wi-Fi & Internet** (~10,253 repeat calls) and *(Technical Troubleshooting** (~5,987 repeat calls) drive over **80% of all company repeat call workload**, recommending 1-click diagnostic tools for frontline agents.
