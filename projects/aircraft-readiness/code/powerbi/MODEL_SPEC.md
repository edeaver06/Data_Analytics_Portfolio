# Power BI data model spec: Aircraft Readiness

Import every table straight from `code/data/export/`. There are 25 tables. Parquet is the tracked copy (Power BI: Get Data → Parquet); matching CSVs are regenerated by `src/build.py` but gitignored. `src/build.py` builds these exports, and there's no copy under `powerbi/`.
Data status follows `docs/schema.md`:
- **Real:** FAA SDR, FAA Registry and GAO-22-104533, which has been verified.
- **Approximated:** hours between reports.
- **Simulation:** NASA C-MAPSS.
- **Synthetic:** the `syn_*` tables, all with `is_synthetic = TRUE`.

**Not related, on purpose:**
- **Synthetic tables vs `dim_aircraft` and `dim_date`:** a real-data date slicer must never filter simulated data.
- **`fct_mc_rate_benchmark`:** its FY2015–21 rows don't overlap `dim_date`, which covers FY2025–26.
- **`syn_fct_backlog_daily` vs `syn_dim_tail`:** it's a fleet-level daily snapshot, so a tail slicer doesn't filter the backlog line.

## Unknown members (no blanks)
- **Missing keys:** missing aircraft, operator and part map to key **-1 `<UNKNOWN>`**. In this data that's 175 reports for aircraft, 578 for operators and 0 for parts. Missing ATA maps to `'UNK'`, and missing stage or precaution to `'-1'`.
- **Aircraft count:** `Aircraft Reporting` excludes -1, giving 6,521 real tails.
- **Rankings:** top-N part, operator and aircraft visuals need a visual filter on key <> -1.
- **Totals:** report counts include the unknown rows, so they still add up to 34,350.

## Code-label caveat (surface it in visuals)
`dim_precaution[label_basis]` flags codes **B, F, G and H** as inferred but unverified, and **I, J and L** as `Unknown`. Together they cover **262 of 2,521 operational interruptions (10.4%)**. Use the `Precaution Label Status` measure (or a `label_basis` contains "unverified" rule) to hatch or lighten those bars, mark them with †, and show the `Unverified Code Footnote` measure.

## Date tables
- **`dim_date`:** run **Mark as date table** on `[date]`. Sort `year_month` by itself and `day_name` by `day_of_week`.
- **`'Sim Date'`:** `ADDCOLUMNS ( CALENDAR ( DATE(2025,1,1), DATE(2025,12,31) ), "Month", FORMAT ( [Date], "yyyy-mm" ) )`, then mark it as a date table.

## Hidden columns
Hide these:
- every key column on the fact side
- every `is_synthetic` column
- `fct_discrepancy[discrepancy_text]`, unless you use it on the drill-through page. You can also remove it in Power Query to save size.
